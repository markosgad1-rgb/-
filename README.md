# تطبيق الحضور والانصراف (Attendance & Check-in App)

تطبيق أندرويد لإدارة حضور وانصراف الموظفين، مبني بـ React + Capacitor بحيث يعمل كتطبيق أندرويد حقيقي (وليس فقط صفحة ويب) مع الوصول لبصمة الإصبع وتحديد الموقع الجغرافي.

## المميزات

- **تسجيل حضور/انصراف** بضغطة زر واحدة، يتطلب:
  - **بصمة الإصبع** (عبر `capacitor-native-biometric`) للتأكد من هوية الموظف.
  - **تحديد الموقع الجغرافي** (عبر `@capacitor/geolocation`) لتسجيل مكان الحضور/الانصراف، مع رابط مباشر لعرضه على خرائط جوجل.
- **إدارة المستخدمين**: المدير العام يمكنه إضافة موظفين، مديرين، أو مديرين عامين آخرين، وتحديد صلاحية كل مستخدم.
- **صلاحيات ثلاثة مستويات**:
  - `موظف`: يسجّل حضوره/انصرافه فقط.
  - `مدير`: يرى تقارير الحضور لكل الموظفين بالإضافة لتسجيل حضوره.
  - `مدير عام`: كل صلاحيات المدير + إدارة المستخدمين (إضافة/حذف).
- **تقارير**: فلترة سجلات الحضور حسب الموظف والتاريخ، مع عرض الموقع ورابط الخريطة لكل حركة.

> **ملاحظة:** البيانات تُخزَّن حالياً على الجهاز نفسه (`localStorage`) كنموذج تجريبي بدون سيرفر. لربط التطبيق بعدة أجهزة/موظفين في نفس الوقت، يجب لاحقاً ربطه بـ API/قاعدة بيانات خلفية.

## التشغيل محلياً (معاينة ويب)

**المتطلبات:** Node.js

1. تثبيت الحزم:
   `npm install`
2. تشغيل المعاينة في المتصفح:
   `npm run dev`

> في المتصفح لا يوجد مستشعر بصمة حقيقي، لذلك يظهر تأكيد بديل (محاكاة) بدلاً من بصمة الإصبع الفعلية. البصمة الحقيقية تعمل فقط عند تشغيل التطبيق على جهاز أندرويد فعلي.

بيانات الدخول الافتراضية عند أول تشغيل:
- اسم المستخدم: `admin`
- كلمة المرور: `admin`

## تحميل ملف APK جاهز (بدون تثبيت أي برنامج)

المشروع فيه GitHub Action (`.github/workflows/build-android.yml`) تبني ملف APK تلقائياً في كل مرة يتم فيها Push على الفرع، وترفعه في قسم **Releases** بالمستودع كملف جاهز للتحميل المباشر على الموبايل:

1. افتح المستودع على GitHub، من القائمة الجانبية اضغط **Releases** (أو الرابط: `Releases` أسفل معلومات المستودع).
2. افتح آخر إصدار باسم "Attendance App APK"، وحمّل ملف `app-debug.apk` من قسم **Assets**.
3. افتح الملف على موبايل الأندرويد لتثبيته — قد يطلب منك تفعيل **"تثبيت من مصادر غير معروفة"** لمتصفحك/تطبيق الملفات أول مرة (من إعدادات الأمان بالموبايل)، وهذا طبيعي لأنه APK تجريبي (debug) وليس من متجر جوجل بلاي.

> إذا لم يظهر أي Release بعد، افتح تبويب **Actions** بالمستودع وتأكد أن آخر تشغيل لـ "Build Android APK" انتهى بنجاح (علامة ✅). يمكنك أيضاً تشغيله يدوياً من Actions عبر زر **Run workflow**.

## بناء تطبيق أندرويد يدوياً (Android Studio)

المشروع يحتوي بالفعل على مجلد `android/` (تم توليده عبر Capacitor). لبناء وتشغيل التطبيق على جهاز/محاكي أندرويد تحتاج جهازاً عليه **Android Studio**:

1. بناء ملفات الويب ومزامنتها مع مشروع أندرويد:
   ```
   npm run build
   npx cap sync android
   ```
2. فتح المشروع في Android Studio:
   ```
   npx cap open android
   ```
   (أو الأمر المختصر: `npm run android` يقوم بالخطوتين السابقتين ثم يفتح Android Studio مباشرة)
3. من داخل Android Studio: اضغط **Run** لتشغيله على جهاز/محاكي، أو **Build > Build Bundle(s)/APK(s) > Build APK(s)** لإنشاء ملف APK قابل للتثبيت.

### الأذونات المطلوبة على أندرويد

تم ضبط `android/app/src/main/AndroidManifest.xml` تلقائياً بالأذونات التالية:
- `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` — لتحديد الموقع عند تسجيل الحضور.
- `USE_BIOMETRIC` / `USE_FINGERPRINT` — لاستخدام بصمة الإصبع المسجّلة على الجهاز.

عند أول استخدام سيطلب التطبيق من المستخدم منح إذن الموقع، ويستخدم بصمة الإصبع المسجّلة بالفعل على إعدادات الجهاز (لا يقوم التطبيق بتخزين بيانات البصمة، بل يعتمد على نظام أندرويد نفسه).

## البنية التقنية

- `App.tsx` — نقطة الدخول الرئيسية وإدارة الحالة والتنقل.
- `components/AttendanceView.tsx` — شاشة تسجيل الحضور/الانصراف.
- `components/UsersView.tsx` — إدارة المستخدمين (للمدير العام).
- `components/ReportsView.tsx` — تقارير الحضور (للمدير/المدير العام).
- `components/LoginView.tsx` — شاشة تسجيل الدخول.
- `services/biometricService.ts` — التحقق من بصمة الإصبع.
- `services/locationService.ts` — تحديد الموقع الجغرافي.
- `capacitor.config.ts` — إعدادات تطبيق Capacitor (اسم الحزمة: `com.company.attendance`).
